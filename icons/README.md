# Extension Icons

Exhibit's icon is a red evidence tag (punched hole, reinforcement ring, string, written lines).

- `icon16.png` - toolbar at 1x
- `icon32.png` - toolbar at 2x (Retina/HiDPI)
- `icon48.png` - extensions page
- `icon128.png` - install dialog and Chrome Web Store

All four are generated by `generate_icons.py` in the project root (requires Pillow):

```bash
pip3 install Pillow
python3 generate_icons.py
```

Each size has its own design in the script's `DESIGNS` table, drawn on that size's pixel
grid: 16 and 32 px drop the string and keep edges on whole pixels so they stay sharp.
Edit the table (or the colours at the top) and re-run the script instead of editing the PNGs.
